# 🎤 STT Sidecar

Локальный VOSK STT сервер с TUI для голосового ввода в [webworx](https://tasks.webworx.ru).

Запускается на **вашей машине** — браузер подключается к нему через `ws://localhost`.  
Не требует серверных изменений. Если sidecar не запущен — голосовой ввод просто недоступен, всё остальное работает как обычно.

## Быстрый старт

```bash
git clone https://github.com/popov/stt-sidecar.git
cd stt-sidecar
./run.sh
```

Первый запуск автоматически скачает модель VOSK (~1.8GB). После загрузки:

```
┌────────────────────────────────────────────┐
│  🎤 STT Sidecar — локальное распознавание  │
│                                            │
│  Параметр          Значение                │
│  WebSocket         ws://localhost:8081      │
│  Модель            ✅ загружена             │
│  Подключения       0                        │
│  Распознано        0                        │
│  Последний текст   —                        │
└────────────────────────────────────────────┘
```

Откройте `tasks.webworx.ru` → микрофон работает.

## Требования

- Python 3.10+
- Микрофон

## Настройка

```bash
# Порт (по умолчанию auto: 8081→8085)
export STT_PORT=9090

# Токен (должен совпадать с VITE_STT_TOKEN в webworx)
export STT_API_KEY=dev-key-123

python tui_app.py
```

## Архитектура

```
Браузер (tasks.webworx.ru)          Ваша машина
┌──────────────────────┐           ┌──────────────────┐
│  Card.vue            │           │  stt-sidecar     │
│  useVoiceTranscription│─ ws ───▶ │  FastAPI + VOSK  │
│  /health check       │◀─http───│  /health          │
└──────────────────────┘           └──────────────────┘
```

## Как это работает

1. `Card.vue` при монтировании проверяет `/health` на localhost:8081
2. Если sidecar найден — показывает кнопки микрофона
3. Пользователь говорит → Audio → `ws://localhost:8081` → VOSK → текст
4. Если sidecar не запущен — жёлтая подсказка со ссылкой на установку
